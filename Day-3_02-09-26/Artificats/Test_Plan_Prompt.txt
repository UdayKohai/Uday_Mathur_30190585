# 12. Entry Criteria
 
Testing can begin when:
 
* Requirements are approved.
* Test environment is available.
* Application build is deployed.
* Test data is available.
* Test cases are reviewed and approved.
* Required tools/access are available.
* Critical dependencies are resolved.
 
---
 
# 13. Exit Criteria
 
Testing can be completed when:
 
* All planned test cases have been executed.
* Critical and High-priority defects are resolved or formally accepted.
* Required regression testing is completed.
* No unresolved blocker defects remain.
* Test coverage meets the agreed target.
* Test execution results are documented.
* Test summary report is prepared.
* Stakeholders provide approval/sign-off.
 
---
 
# 14. Suspension Criteria
 
Testing may be suspended when:
 
* Application is unavailable.
* Critical functionality is completely blocked.
* Test environment is unstable.
* Required test data is unavailable.
* A critical build issue prevents meaningful testing.
 
---
 
# 15. Resumption Criteria
 
Testing will resume when:
 
* Blocking defects are resolved.
* Stable application build is deployed.
* Test environment becomes available.
* Required test data is available.
* Dependencies are resolved.
 
---
 
# 16. Defect Management
 
### Defect Lifecycle
 
New → Assigned → Open → Fixed → Retest → Verified → Closed
 
Possible additional statuses:
 
* Reopened
* Rejected
* Duplicate
* Deferred
* Cannot Reproduce
* Won't Fix
 
### Defect Severity
 
| Severity | Description                                                |
| -------- | ---------------------------------------------------------- |
| Critical | Application/business-critical functionality is unavailable |
| High     | Major functionality is impacted                            |
| Medium   | Functionality is partially impacted                        |
| Low      | Minor issue with limited impact                            |
 
### Defect Priority
 
| Priority | Description            |
| -------- | ---------------------- |
| P1       | Immediate fix required |
| P2       | High priority          |
| P3       | Normal priority        |
| P4       | Low priority           |
