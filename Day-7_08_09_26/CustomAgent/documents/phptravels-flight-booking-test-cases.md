# PHPTRAVELS Flight Booking Test Cases

**Source test plan:** [phptravels-flight-booking-test-plan.md](phptravels-flight-booking-test-plan.md)  
**Application:** https://phptravels.net/  
**Prepared:** 2026-09-08

## Scope and Execution Notes

These test cases cover only the flight-booking test plan. Hotel-only, visa-only, and unrelated account-registration functionality is excluded. Use synthetic passenger data and approved sandbox payment values only. Generate future dates at runtime because the demo data and inventory may change. Cases marked **Conditional** require an approved supplier fixture, payment fixture, test mailbox, test account, or test environment.

## Priority Definitions

- **P0:** Critical flight booking, payment, security, data-integrity, or availability path.
- **P1:** High-value functional, validation, integration, accessibility, or compatibility behavior.
- **P2:** Secondary localization, analytics, or lower-risk coverage.
- **P3:** No P3 cases are required by the source flight-booking test plan.
